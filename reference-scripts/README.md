# 实战脚本（reference-scripts/）

来自一次真实拆解：《这个人明明很强却偏要坑萝莉师傅》（132.6万字 / 589章）。

这些脚本依赖那本书的具体路径，**不能直接照跑**——
它们是给你**抄写法**用的参考实现。

## 怎么用

1. 改每个脚本顶部的 `SRC`（小说路径）和 `OUT`（产出目录）
2. 按顺序跑，每步看打印摘要
3. 最后跑终检脚本确认 ALL PASS

详见上级目录的 `SKILL.md`。
